# Material differences from the human audits

Where a generated report differs materially from the completed human audit for
the same site, what each says, and which the evidence supports. The site-by-site
table of parcels, districts, levels and tower counts is `comparison.md`, which is
regenerated by `tools/calibrate.py`. This file is kept by hand, because a verdict
on evidence is a judgement.

Recommendation agrees on all five sites (Proceed to SCIP), and every parcel the
human audits list is matched in ours. The differences are below.

Tower counts were recomputed on 2026-11-21 from the FCC bulk file dated
2026-11-15. Everything else is from the calibration run recorded in
`comparison.md`; re-run the calibration after any code change and check these
still hold.

## What the audits do not carry and this output adds

- Sec. 8.004.220 subsections .16 (records), .17 (inspection every 24 months) and
  .18 (abandonment) are cut off in the 2024 audits' quotation of the section.
- Council Bluffs measures height to the top of the antenna from natural
  undisturbed ground, which matters when a RAD is close to 200 ft.
- A disposition and reason for every parcel, and the binding constraint for each
  one that was excluded.
